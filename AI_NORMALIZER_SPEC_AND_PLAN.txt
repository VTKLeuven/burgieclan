================================================================================
           VTK BURGIECLAN - AI DOCUMENT NORMALIZER & ARCHIVIST SPECIFICATION
================================================================================

PROJECT: VTK Burgieclan (Archival Migration of 16,905 Documents across 389 Courses)
TARGET: Generate consistent display titles, verified authors, orthogonal tags,
        accurate academic years, and clean category mapping for every document.

--------------------------------------------------------------------------------
1. ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------

The AI Normalizer operates on course-grouped batches. For each course, an LLM
acts as an expert Academic Archivist for VTK (KU Leuven Faculty of Engineering
Science).

The LLM receives:
- Official Course Context (Course Code + Dutch & English Course Name)
- Full Folder Path Context (degree programme, semester, module folder)
- Original Filename & Extension
- Extracted Page 1 Text Preview (and Pages 2-3 fallback text for cover pages)
- Physical Properties (Page count, Scanned/Handwritten vs Digital LaTeX/Word flag)

The LLM outputs a structured JSON array matching a strict schema.

--------------------------------------------------------------------------------
2. CANONICAL NAMING CONVENTIONS BY MATERIAL TYPE
--------------------------------------------------------------------------------

Every generated `display_title` must strictly follow these standard templates:

A. EXAMS (Category ID: 2 - Examens)
   Template:  Examen [Dag] [Maand] [Jaar] [- Deel X] [(Oplossing|Modeloplossing|Opgave)] [(Auteur)]
              Examenvragen [Sessie / Jaar] [- Onderwerp] [(Auteur)]
   Examples:  - "Examen 19 Juni 2017 - Deel 1 (Oplossing)"
              - "Examen Januari 2021 (Opgave)"
              - "Examen 2 September 2019 (Herexamen) (Oplossing) (Student 064)"
              - "Examenvragen Juni 2023 (Kobe)"
              - "Examen Reconstructie 2022 - Vraag 1 & 2"

B. EXERCISE SESSIONS & HOMEWORK (Category ID: 4 - Oefenzittingen)
   Template:  Oefenzitting [Nr / Onderwerp] [- Deel X] [(Oplossing|Verslag)] [(Auteur)]
              Bundel Oefeningen [- Onderwerp] [(Jaar)]
   Examples:  - "Oefenzitting 3 - Pompen en Compressoren (Oplossing)"
              - "Oefenzitting 5 - Fourier Transformaties (Opgave)"
              - "Huiswerk 2 - Statica van Vakwerken (Oplossing) (Student 083)"
              - "Bundel Oefeningen Pompen & Compressoren (2024 - 2025)"
              - "P&O Verslag - Reverse Engineering Tandwielkast"

C. SUMMARIES & NOTES (Category ID: 3 - Samenvattingen)
   Template:  Samenvatting [- Deel X] [- Onderwerp / Hoofdstukken] [(Auteur)]
              Lesnotities [- Deel X] [- Onderwerp] [(Auteur)]
   Examples:  - "Samenvatting Deel 2 - Matrixmethodes (Student 083)"
              - "Lesnotities Hoofdstuk 1-6 (Student 053)"
              - "Formularium & Overzicht Integratietechnieken"

D. LECTURE SLIDES (Category ID: 6 - Slides / Lesmateriaal)
   Template:  Slides [- Hoofdstuk/Les X] [- Onderwerp] [(Prof. Naam)]
   Examples:  - "Slides Les 5 - Management Challenges (Prof. Dejaeger)"
              - "Slides Hoofdstuk 3 - Lineaire Systemen"

E. LABS & CODE (Category ID: 7 - Labo & Code)
   Template:  Labo [Nr / Onderwerp] - [Scriptnaam / Functie] [(Taal)]
   Examples:  - "Labo 2 - Filter Design en FFT (MATLAB)"
              - "Labo Machine Learning - Distort Random Chance (Python)"

F. MIDTERMS / TTT (Category ID: 5 - TTT's)
   Template:  TTT [Nr / Datum] [- Vragenreeks X] [(Oplossing|Opgave)] [(Auteur)]
   Examples:  - "TTT 1 Oktober 2014 - Vragenreeks 1 (Opgave)"
              - "TTT November 2018 (Oplossing) (Student 105)"

G. PHOTO SEQUENCES (Images in subfolders e.g. 106 page scans)
   Rule:      Automatically indexed as "[Folder Name] (p. {idx}/{total})".
              Never name image sequences identically!

--------------------------------------------------------------------------------
3. ORTHOGONAL TAG TAXONOMY (Single Source of Truth: tag_vocabulary.json)
--------------------------------------------------------------------------------

RULE: Tags must be strictly orthogonal to the category.
- NEVER add 'Slides' under Category 6 (Slides / Lesmateriaal).
- NEVER add 'Code / Script' under Category 7 (Labo & Code).
- NEVER add 'Oefeningen' under Category 4 (Oefenzittingen).
- NEVER add 'Samenvatting' under Category 3 (Samenvattingen).

Allowed Tag Vocabulary:
- Solution State:    'Oplossing', 'Oplossing (Student)', 'Modeloplossing', 'Opgave (Blanco)'
- Exam Sessions:     'Januari', 'Juni', 'Herexamen (2de zit)', 'Tussentijds (Midterm)',
                     'Reconstructie / Vragen', 'Oefeningen (Examen)'
- Format & Nature:   'Handgeschreven', 'Theorie', 'Lesnotities', 'Verslag / Project',
                     'Formularium', 'Bundel / Alle', 'Meerkeuze', 'Mondeling'
- Scope / Division:  'Deel 1', 'Deel 2', 'Deel 3', 'Deel 4'
- Language:          'English'

--------------------------------------------------------------------------------
4. AUTHOR & YEAR EXTRACTION RULES
--------------------------------------------------------------------------------

- Authors:
  - If a student creator name is detected in the filename, path, or Page 1 text
    (e.g., "door Student 064", "Student 083", "Student 053"), populate `author`: "Full Name"
    and append `(Full Name)` to the `display_title`.
  - Do NOT mistake professor names (e.g. "Prof. Dejaeger", "Prof. Indekeu") for student authors.
    Professor names remain in the title e.g. `(Prof. Dejaeger)`.
  - Coursework Carve-Out: Student names on graded take-home assignments or individual submissions
    must NOT be promoted to author credits.

- Academic Years:
  - Format: Strictly "YYYY - YYYY" (e.g. "2018 - 2019", with Y2 = Y1 + 1 and Y1 <= 2025).
  - Only set if the year explicitly appears in filename, session, or Page 1 text.
  - If year is unverified/unknown, return `null`. The validator rejects invented years.

--------------------------------------------------------------------------------
6. MECHANICAL VALIDATION & COLLISION GUARDRAILS (08i Script)
--------------------------------------------------------------------------------

1. Exact ID & Length Check: Hard-fails if any file_id is dropped, duplicated, or misaligned.
2. Mechanical Year Guard: Asserts year string literally appears in input; nulls hallucinations.
3. Length Capping: Titles capped at 200 chars (safe for VARCHAR(255) and suffixes).
4. Per-Course Collision Disambiguation: Detects identical titles in the same course and appends part indices.
5. Vocabulary Enforcement: Strips any non-vocabulary tags and non-orthogonal category mirrors.
6. Field-by-Field Merge: Merges each field independently with deterministic fallback.
